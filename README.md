# Masquer

Plugin Hermes. Il cache emails, téléphones français, IBAN, adresses claires et clés avant l'envoi au modèle. Toi tu continues à tout lire. Les outils retrouvent les vraies valeurs.

Ce n'est pas une conformité RGPD.

## Installer

```bash
hermes plugins install Kavyrocom/hermes-plugin-masquer --enable
```

Puis, dans une nouvelle session :

- `/masquer status`
- `/masquer on`
- `/masquer off`
- `/masquer ajouter Marie Dupont`
- `/masquer` suivi d'un texte ou d'un fichier
